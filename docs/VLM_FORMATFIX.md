# Исправление формата ответа v2

Это тот же Qwen3-VL-4B, те же промпты и выбор кадров. Новый код допускает до 32 ссылок модели на реальные входные кадры. После проверки всех ссылок он выбирает первый, средний и последний кадр. Публичное API продолжает выдавать не более трёх JPEG на событие. Неверные индексы, повторения, неизвестные категории и противоречивые статусы не игнорируются.

В запуске `vlm-v2-smoke-20261018-055256` два ответа были отклонены только за лишние ссылки на кадры. Сохранённые ответы пересчитаны локально без GPU и без изменения разметки: TP=2, FP=1, FN=1, TN=2, F1=0.667 на шести диагностических видео. Это пересчёт после исправления формата, не новый запуск модели и не независимый тест. Общий F1 не подтверждает правильность всех категорий и нормативных выводов.

Остались ошибки: Х-4 пропущен, Х-27 ошибочно отмечен как уход во время обслуживания; в Х-26 есть правильный визуальный кандидат оставленной купюры и лишний неподтверждённый тип ухода во время обслуживания. Для оставленной купюры время указано до фактического ухода. Х-40 распознано как личная одежда, но точные границы и доказательства также требуют просмотра. Развёртывание как проверенного банковского детектора не одобрено.

## Установить исправление отдельно от v2

Загрузить `brev-vlm-v2fix.zip` в корень проекта. Модель и пакеты повторно не скачиваются.

```bash
cd ~/workspace/datathon_cashier
.venv/bin/python -m zipfile -e brev-vlm-v2fix.zip .
```

Результат исходного smoke уже разобран локально. Если нужна такая же восстановленная копия на Brev, выполнить без GPU:

```bash
.venv/bin/python brev-vlm-v2fix/scripts/replay_vlm.py --run-dir data/runs/vlm-v2-smoke-20261018-055256 --data-dir data
```

Скрипт не перезаписывает исходный запуск. Проверяет хэши сохранённых артефактов, видео, времена и исходные метки; сохраняет старые ошибки, исходные ответы и выбранные кадры. В новом отчёте явно указано `model_rerun=false`. Хэши декодированных пикселей дополнительно сравниваются, но могут зависеть от версии декодера на разных ОС.

Для нового диагностического запуска использовать `brev-vlm-v2fix/scripts/run_vlm_brev.py` с прежними аргументами. На `--scope reviewed` будет 20 видео, на `--scope smoke` — те же шесть. Фикс не улучшает визуальную модель и не устраняет ложную юридическую классификацию; до публичной сдачи нужна проверка именно событий и правил, затем реального API и контейнера.
