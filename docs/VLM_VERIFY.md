# Диагностический прогон VLM с проверкой фактических условий

Для сдачи и проверки полного сервиса использовать `brev-service-v1.zip` и
инструкцию `docs/SERVICE_BREV.md` в исходном проекте. Этот отдельный пакет нужен
только для повторного диагностического прогона без HTTP.

```bash
cd ~/workspace/datathon_cashier
.venv/bin/python -m zipfile -e brev-vlm-v3-verify.zip .
CC=/usr/bin/gcc CXX=/usr/bin/g++ .venv/bin/python -u brev-vlm-v3-verify/scripts/run_vlm_brev.py --data-dir data --scope smoke
```

Проверка использует те же веса и шесть видео, но новый этап подтверждения условий
предложенного события. Это новый вариант обработки, а не повтор старого v2fix.
Старые ZIP и метрики сохранены. Улучшение качества необходимо измерить, а не
предполагать. Имена файлов, метки и комментарии не входят в запрос к модели.
