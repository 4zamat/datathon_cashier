## Что пересмотрено

Это не покадровая проверка всей записи. Статус «на проверку» не определяет класс. Итоговая метка также не копируется из таблицы организаторов.

После объединения точных дублей 4/47 и 5/48 остаются 40 уникальных роликов:

- **6 положительных:** 4, 26, 34, 38, 40, 46. Метка означает визуально обоснованный кандидат на проверку человеком.
- **14 отрицательных:** 3, 5, 8, 12, 14, 16, 21, 23, 25, 27, 29, 31, 43, 45. На просмотренном материале не обнаружен обоснованный признак; это не подтверждение невидимых банковских проверок.
- **20 спорных:** 1, 2, 10, 11, 13, 15, 17, 18, 19, 20, 22, 24, 28, 30, 32, 33, 35, 37, 39, 44. Полностью исключены из обучения и бинарных метрик.

Причина каждого решения, исходный комментарий и временной интервал сохранены в `dataset/dataset_manifest.json`, полный список — в `dataset/video_review.csv`. Исходная таблица включена только для аудита. Имена исходных видео сохранены, включая кириллическую Х.

Особенности правового обоснования: в Х-26 видны оставленные деньги, но происхождение денег требует проверки для применения п. 20. В Х-46 видна используемая сотрудником кружка; напиток и предмет рядом не называются кофе или едой. В этих строках явно сохранены условия применимости нормы. Отсутствие показанного удостоверения, отдельного УФ-детектора или видимой блокировки ноутбука само по себе не доказывает нарушение. Набор не прошёл независимую проверку банковским экспертом.

## Запуск в открытом терминале Brev

Загрузите **только** `brev-reviewed-v4.zip` в `/home/ubuntu/workspace/datathon_cashier/`. Видео уже находятся в `data/videos/`, а сохранённый энкодер — в `models/brev_v2/encoder_resnet18.pt`. Переключать ветку не требуется: архив распаковывается в отдельную папку.

```bash
cd ~/workspace/datathon_cashier
.venv/bin/python -m zipfile -e brev-reviewed-v4.zip .
.venv/bin/python -u brev-reviewed-v4/scripts/run_independent_brev.py --data-dir data
```

Не подменяйте `data/labels.csv`. Новый запуск читает свой JSON с исправленными метками. Проверяет контрольные суммы архива и видео. Использует уже установленные numpy, OpenCV, torch и torchvision; ничего автоматически не скачивает. Если сохранённый энкодер расположен иначе, добавьте `--encoder-weights /полный/путь/encoder_resnet18.pt`.

## Что делает обучение

1. Замороженный ResNet18 извлекает признаки с частотой 2 fps. Полный кадр сохраняет пропорции и дополняется полями до 224×224. Вторая область — верхние 70% изображения, чтобы крупнее видеть рабочее место. Для каждой области усредняются обычное и зеркальное представления. Это фиксированное преобразование; ручные рамки и метки не используются при прогнозе.
2. Признаки учитывают текущую сцену и изменение относительно первых двух секунд этого же ролика. Обучается линейный бинарный классификатор, 60 эпох с фиксированной регуляризацией. Это не YOLO, не дообучение всех весов и не классификатор статей правил.
3. Положительные кадры берутся только из размеченных интервалов. Остальные кадры положительного ролика игнорируются, чтобы случайно не учить их как норму. Спорные ролики не используются ни целиком, ни отдельными кадрами.
4. Четыре внешние проверки исключают целиком один ракурс. Порог выбирается только по внутренним проверкам трёх остальных ракурсов. Учитываются дубли и общие сцены. Один ракурс содержит только положительные видео, поэтому его balanced accuracy не определена; общая метрика считается по всем 20 прогнозам.
5. Финальная модель обучается на всех 20 допустимых видео. Её порог — медиана четырёх внутренних порогов. Прогнозы этой финальной модели на обучающих видео используются только для проверки сохранения/загрузки, не как оценка качества.
6. Отдельный процесс загружает сохранённую модель и сравнивает результат без разрешённых Python socket-соединений. Проверка загрузки не подтверждает качество и не заменяет полноценную проверку Docker без сети.

## Что скачать после завершения

Терминал напечатает точные пути:

- `SMALL ZIP (send this)` — небольшой архив с головой модели, конфигурацией, метриками, аудитом разбиений, HTML и кодом; без повторной копии энкодера. Передать Азамату.
- `METRICS` — отдельный маленький JSON, можно прислать первым.
- `VISUAL REPORT` — `data/runs/reviewed-v4-.../review.html`, открыть в браузере и проверить ошибки. Уже входит в маленький архив.
- `FULL ZIP` — полная копия, включая энкодер; сохранить до удаления облачной машины.

В маленьком архиве указан SHA-256 отсутствующего энкодера. Для восстановления нужен совпадающий энкодер из полного архива или сохранённого Brev v2. Полный архив не содержит исходных видео.

`COMPLETE: True` — выполнены обучение, экспорт и проверка загрузки. **Это не означает хорошее качество.** `QUALITY SCREEN` проверяет заранее заданные минимумы: полнота ≥ 0.8, точность ≥ 0.7, balanced accuracy ≥ 0.7 и F1 выше постоянного «нарушение». Даже успешный экран на 20 роликах не подтверждает качество на всем датасете или новых камерах. Все ролики просмотрены при подготовке разметки; результаты являются проверкой разработки.

Если качество плохое, не улучшайте цифры исключением ошибок или подбором порога по внешней проверке. Следующий полезный материал — дополнительные независимые примеры конкретных событий и проверка спорных случаев. Сохраняйте неудачные результаты. Бинарный score нельзя превращать в конкретный пункт закона без отдельного распознавания события.
