# Локальная разметка видео

Страница позволяет смотреть записи из `data/videos`, отмечать события, писать комментарии и рисовать рамки на выбранных кадрах. Это отдельное рабочее место разметчика. Основной FastAPI-сервис анализа и его API не меняются.

## Запуск

На Windows дважды нажмите **`annotate.cmd`** в корне проекта, затем откройте **http://127.0.0.1:8001**. Окно запуска должно оставаться открытым. Для остановки — `Ctrl+C` в этом окне.

Или из терминала в папке проекта:

```powershell
.\.venv\Scripts\python.exe -m scripts.annotate
```

Linux/macOS, после активации существующего окружения:

```bash
python -m scripts.annotate
```

Используются имеющиеся зависимости `requirements.txt`; Torch, GPU, облако и ключ API не нужны. Для первого запуска на другом компьютере создайте Python 3.11+ окружение и установите `requirements.txt`. Для воспроизведения MOV рекомендуется установленный **FFmpeg** в PATH. Страница автоматически создаёт MP4-копию для браузера без перекодирования видеопотока и без звука. Это работает для совместимых кодеков, включая H.264 в текущем датасете. Если FFmpeg не найден, браузер получает исходный MOV; поддержка зависит от браузера и кодека. Исходные видео не изменяются.

Сервер слушает только `127.0.0.1`. Данные не отправляются во внешние сервисы. Не публикуйте этот порт через туннель: интерфейс предназначен для локальной работы. Для другой папки данных или занятого порта:

```bash
python -m scripts.annotate --data-dir /path/to/data --port 8002
```

Добавили новые видео — перезапустите сервер. Имена видео, включая латинскую X и кириллическую Х, сохраняются точно.

## Сначала события

1. Выберите видео слева. Фильтр «Пять видео для проверки» показывает Х-21, Х-23, Х-30, Х-38, Х-48. Оценки модели и исходные ответы не показываются.
2. В поле **«Кто размечает»** укажите имя. Оно запомнится в этом браузере.
3. Смотрите запись целиком. В начале действия нажмите **«Начало события»**, в конце — **«Конец события»**. Время можно уточнить вручную в секундах от начала записи.
4. Напишите, что действительно видно: кто что сделал, что было до и после, какая часть действия скрыта. Выберите тип и оценку. Если информации недостаточно — «Неизвестно / нужна проверка» и «Неясно».
5. Нажмите **«Добавить событие»**. У одного видео может быть несколько событий. Время в карточке перематывает видео; событие можно изменить или удалить.
6. Добавьте общие заметки. **«Я просмотрел(а) запись целиком»** отмечает завершённый просмотр, а не автоматически нормальное видео. Для нормального интервала добавьте событие «Нормальный фрагмент» с оценкой «Нарушений не видно».
7. Если установили одинаковую или связанную сцену, укажите общее `scene_group_id`, например `scene_01`. Соседние фрагменты и дубли нельзя разносить между train и test. Не назначайте разные группы только из-за разных имён файлов.

Клавиши вне текстовых полей: `Пробел` — воспроизведение/пауза, `[` и `]` — начало и конец, стрелки влево/вправо — шаг 0,5 с. `Ctrl+S` сохраняет документ. Кнопки и поля работают независимо от раскладки клавиатуры.

## Затем рамки

1. Поставьте видео на паузу и нажмите **«Зафиксировать кадр»**. Сервер извлечёт исходный кадр, сохранит JPEG и покажет фактический таймкод и номер кадра. При переменной частоте кадров он может немного отличаться от времени плеера — ориентируйтесь на показанный JPEG.
2. Выберите **«Новый объект»**, нажмите **«+ Новая рамка»** и протяните прямоугольник мышью. Следующие рамки можно рисовать сразу, в том числе поверх предыдущих. Смена класса в поле «Новый объект» также включает рисование. Доступны люди, деньги, кисти рук, телефоны, лотки, места хранения, ноутбуки, счётчики банкнот, детекторы банкнот и сумки.
3. В режиме **«Выбрать / двигать»** нажмите на рамку. Её можно переместить, изменить размер за нижний правый угол, исправить класс, отметить перекрытие и добавить комментарий. Класс «Другое» предназначен для черновых случаев; перед обучением его нужно разобрать.
4. Размечайте все различимые экземпляры согласованных классов на выбранном кадре. Не угадывайте предмет, если его нельзя распознать. Сохраняйте кадры до действия, во время и после, а также нормальные примеры.
5. Выберите область проверки: **«Оборудование»** (сейф, ноутбук, счётчик, детектор) или **«Все 10 классов объектов»**. Только после проверки всех видимых экземпляров этих классов включите **«Все видимые объекты указанного набора размечены»**. Изменение рамки снимает отметку. Оборудование экспортируется отдельно: отсутствие рамок людей на таком кадре не означает отсутствия людей. Для подтверждения всех классов нужно также разобрать «Другое». Подтверждённый кадр без рамок — отрицательный пример для выбранных объектов, а не метка отсутствия нарушения.

Созданные ассистентом рамки помечены «ИИ» и имеют `source=assistant`, `annotator` и `reviewed_by`. Ручное изменение рамки записывает автора правки. Проверка четырёх классов оборудования не подтверждает полноту разметки сумок, людей, денег и рук. Старые подтверждения шести классов не превращаются автоматически в подтверждение десяти.

`layout_group_id` и `layout_notes` описывают расстановку оборудования, отображаются отдельно от группы сцены и сохраняются в экспорте. Одинаковая расстановка не доказывает, что записи относятся к одному эпизоду; различная расстановка не гарантирует независимость записей. Для разделения обучения и проверки нужно отдельно согласовать `scene_group_id`. Нельзя механически копировать рамки на все видео одной расстановки: камера, предметы и перекрытия меняются.

Рамки относятся к конкретному JPEG. Координаты JSON/CSV — `x,y,width,height` от верхнего левого угла, нормированные к диапазону 0…1. В YOLO TXT они переводятся в центр `x,y` и размер. Размер исходного кадра, его индекс и время сохраняются отдельно. Рамки автоматически не распространяются на остальные кадры; трекинг и зоны-полигоны пока не реализованы.

При выборе видео открывается последний добавленный кадр. Более ранние кадры доступны по кнопкам с таймкодами под редактором; они сохраняются вместе со своими рамками.

## Где сохраняется и что передать

Автосохранение срабатывает примерно через секунду после изменения. Проверяйте надпись **«Сохранено на компьютере»**. Незаполненная форма события также сохраняется как черновик, но в CSV событие войдёт только после нажатия «Добавить событие». При ошибке данные остаются в странице, показывается сообщение; кнопка «Скачать текущий черновик JSON» позволяет сохранить их отдельно.

```text
data/annotations/local/
  documents/    # текущая разметка, один JSON на видео
  history/      # предыдущие сохранённые версии
  frames/       # JPEG и метаданные зафиксированных кадров
  exports/      # созданные архивы
data/annotation_cache/  # MP4-копии для воспроизведения
```

Для передачи команде нажмите **«Скачать разметку ZIP»**. В архиве:

- `documents/` — все сохранённые записи, включая черновик формы и общие комментарии;
- `events.csv` — события с заполненными автором и группой сцены, формат существующего валидатора;
- `events_draft.csv` — добавленные события, для которых ещё не указали группу;
- `video_reviews.csv` — состояние просмотра, комментарии, группы и SHA-256 исходников;
- `objects.csv`, `frames/` — все рамки и исходные кадры без нарисованных поверх линий, включая ещё не подтверждённые; в CSV указаны автор, источник и проверенные классы;
- `yolo/images/`, `yolo/labels/`, `yolo/classes.txt` — кадры с проверкой всех 10 классов;
- `equipment_yolo/images/`, `equipment_yolo/labels/`, `equipment_yolo/classes.txt` — кадры с проверкой 4 классов оборудования; здесь собственная нумерация классов, её нельзя смешивать с `yolo/classes.txt`;
- `manifest.json` — числа записей и предупреждения; `rules_reference.json` — использованные правила.

Архив не содержит исходные видео. Разметка, кадры и копии видео лежат в игнорируемой Git папке `data/`; передавайте архив приватно. Для восстановления рабочего места целиком скопируйте папку `data/annotations/local` вместе с теми же исходными видео. ZIP — обменный экспорт, автоматической загрузки такого ZIP через страницу пока нет. Разметку двух участников нужно согласовать перед объединением; не перезаписывайте их JSON друг другом.

Два окна не могут незаметно перезаписать одно и то же видео: сервер проверяет номер версии и при конфликте предлагает скачать текущий черновик и обновить страницу.

После распаковки экспорта проверка CSV:

```bash
python scripts/validate_annotations.py --events path/to/events.csv --allow-partial
```

Это проверка формата, не подтверждение правильности наблюдений. Разметка не переписывает `data/labels.csv`, не меняет исходный Excel и не запускает обучение. Текущий бинарный `train_laptop.py` не читает события и рамки: следующий этап — согласовать категории, проверить данные и группы, подготовить отдельный обучающий набор. Тестовые видео, на ошибках которых уже меняли решение, больше не являются независимой финальной проверкой.

Один опорный кадр на видео полезен для проверки расположения оборудования. Это ещё не полноценный датасет действий: для детекции денег, рук и взаимодействий нужны дополнительные кадры из событий, а для обучения оборудования — разнообразные ракурсы, перекрытия и независимая проверка. Точные дубли и соседние фрагменты должны оставаться в одной части выборки.
