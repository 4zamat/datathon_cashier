# Исправления и проверка, 17.10.2026

Основа — `2d31a02`, первый ноутбучный baseline. Его агрегированные результаты сохранены, веса пока не переданы на машину интегратора.

## Исправлено

- Кэш признаков теперь FP32 и имеет новый ключ; повторное чтение не округляет первый результат до FP16. Для локального энкодера ключ включает хэш весов.
- Линейная голова использует полную взвешенную функцию потерь вместо случайного знаменателя внутри minibatch. Это новая процедура, старые метрики ей не приписываются.
- Считаются все исключённые группы; добавлена ручная группировка похожих сцен, включая сцены с разными классами. При невозможности корректного разбиения запуск останавливается.
- Записываются хэши фактического кода, флаг незакоммиченных изменений, версии split CSV и весов. Проверяется неизменность видео. Старые результаты и разбиения защищены от перезаписи.
- Загрузка проверяет поддерживаемые преобразования и использует сохранённую частоту кадров. Проверка повторной загрузки сверяет также время с сохранёнными предсказаниями.
- Ошибки оценки дают ненулевой код выхода, покрытие и число ошибок видны; модель и константные baseline сравниваются на одинаковых успешно обработанных видео.
- Экспортёр сохраняет приватный архив с хэшами без видео, `.env`, кэша и виртуального окружения. Неполная передача явно помечается.
- В каталог добавлены четыре категории по п. 12, 20, 22 предоставленного PDF № 231. Ссылка из каталога также добавляется к описанию реального события. Источники, цитаты и ограничения — `docs/RULES_VERIFIED.md`.
- Добавлены схема наблюдений, валидатор, отдельные задания команды и инструкции запуска/передачи/Brev.

## Выполненные проверки

- `python -m unittest discover -s tests -v`: 33 теста, 32 прошли, один пропущен из-за отсутствия старого локального `data/splits/laptop_baseline/`. API, очередь, таймаут, очистка, правила, архив, кэш и вспомогательные ML-функции проверены без Torch.
- CLI всех шести скриптов работает как напрямую, так и через `python -m scripts.<имя>`; компиляция Python-исходников успешна.
- Подготовка на настоящих 42 исходных файлах: SHA-256 совпали, 40 уникальных содержимых, 2 исключённых файла, один объединённый дубль, 39 используемых видео, train/val/test = 23/8/8. Новые split CSV проверены на непересечение отдельно от теста старого каталога.
- Исходные labels.csv и видео не изменены. Подготовлен приватный черновик разметки с 42 путями и длительностями; просмотренные человеком события не выдумывались.

Схожие сцены сверх побайтовых дублей ещё требуют ручного решения. Текущая временная оценка не является независимой проверкой на новых ракурсах. API продолжает использовать Dummy; `demo_violation` остаётся технической заглушкой.
